Banking Risk Intelligence Agent Project Link

Multi-agent financial intelligence system converting unstructured financial news into structured, evidence-backed risk insights. Four agents collaborate to classify risk, retrieve evidence, generate audit-ready summaries with citations, and self-validate outputs to reduce hallucinations.

4-Agent Pipeline
📰
Financial News Input
Unstructured text · Market data · Reports
🗂️
Planner Agent
Query Decomposition & Orchestration
  • Decompose complex news into risk sub-questions
  • Classify intent and assign retrieval strategy
  • Maintain LangGraph state across all agents
🔬
Research Agent
Evidence Retrieval · TF-IDF + Cosine
  • Retrieve supporting evidence per sub-question
  • Rank by relevance using TF-IDF + cosine similarity
  • Return source-attributed evidence chunks
📝
Answer Agent
Risk Synthesis & Citation
  • Synthesise risk classification from evidence
  • Generate audit-ready summaries with citations
  • Structure output for downstream validation
🧐
Critic Agent
Output Validation & Hallucination Guard
  • Score each claim against retrieved evidence
  • Flag unsupported or hallucinated statements
  • Route back to Answer Agent if confidence < threshold
↩ Revision loop: Critic → Answer Agent (max 3 iterations)
