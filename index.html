Flagship Project

Roche Multi-Agent Lab Report Pipeline

Architected and deployed a production multi-agent system at Roche to automate lab report processing end-to-end. A planner agent decomposes incoming reports and routes tasks across specialist agents for extraction, validation, and structured output generation. Reduced average processing time from 40 minutes to 100 seconds, a 96% reduction, while maintaining clinical-grade accuracy. Built on LangGraph with Azure AI Foundry, FastAPI, and Docker on Azure.
